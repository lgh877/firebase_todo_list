# firebase_todo_list

Firebase를 사용한 todolist 앱 숙제. 오늘 수업에 못 온 기혁님께서 이미지 불러오는 기능도 참고하시면 좋을 것이라고 생각하여 이미지 입력기능도 넣어는 봤으나, 이미지가 입력되지 않은 경우 아이콘으로 띄우도록 했고, 휴지통에 등록된 todo list들의 경우 이미지를 사용하지 않도록 조치했습니다.
